1 · System & infrastructure

One container: React frontend → FastAPI → service layer → private SQLite. Everything external is opt-in.

Standalone (no Home Assistant): the same container runs behind an optional TLS reverse proxy instead of HA ingress - see reverse-proxy.md. Bind it to localhost or a header-stripping proxy (the app trusts X-Remote-User-*).

2 · Request flow

A read/write request, ingress → backend → service → SQLite and back.

3 · Import & categorisation flow

Two phases: upload → preview (dedup), then confirm → persist with the rules → vendor → keyword → FX pipeline per row.

4 · AI gateway & privacy gate

AI is off by default and opt-in. One gateway (ai_service) decides whether AI may run, redacts every cloud-bound payload at a single choke point, audits the call, and returns a suggestion the user must apply. AI never writes a category itself.

Why it is safe by default: the default mode is strict-local (no external calls at all). Cloud modes are opt-in and only ever send the redacted allow-list payload built at one choke point (redact_for_cloud in services/redaction.py). Batch AI runs in local_llm only; a cloud batch stages every redacted payload for one-shot approval first. Vision image-extract can not be redacted, so it refuses to auto-send under cloud_auto without explicit approval.

  redact -- cloud_auto --> autosend["send automatically"]
  approve --> cep["public cloud endpoint (SSRF guard)"]
  autosend --> cep
  lep --> sug["provider reply -> suggestion"]
  cep --> sug
  sug --> apply["AI never writes; user applies -> confidence 1.0 (audited)"]

5 · Data model - core spine

The full model has ~30 tables (spec §12); this shows the core relationships.

Other groups hang off the same ACCOUNT / TRANSACTION / USER spine: savings (SavingsBalance, SavingsGoal) · investments (AccountValue, Holding, HoldingPrice) · assets (Asset, AssetLog) · AI (AIRequest) · review (ReviewItem) · energy (EnergySnapshot) · import profiles (ImportProfile) · Curve funding links (CurveFundingLink) · subscriptions · rules · budgets · tags · child allowance (ChildAllocation) · MFA (UserSession) · audit (AuditLog). Retention adds an archived_at column to transactions / receipts / AI-requests / audit-logs.

6 · Deployment - add-on image

Multi-stage build: the frontend is built with Node, then served by the Python runtime alongside the backend; data lives on a private volume.

The runtime image is multi-arch (amd64 / arm64). At-rest DB encryption (SQLCipher) ships as a prebuilt wheel on amd64; on arm64 the sqlcipher3 wheel is compiled in a throwaway build stage so the Pi gets it too. It's opt-in - off by default.
